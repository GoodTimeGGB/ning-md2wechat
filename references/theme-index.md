## 设计哲学

**有特色，不模仿。** 每种主题都是"AI博主"的视觉表达——懂技术、有人味、看着舒服。

## 通用排版舒适度规则（所有主题共享）

无论选哪个主题，以下规则不可违反：

```
正文字号:     16px

段间距:       22px
章节间距:     40px
字间距:       0.3-0.5px
标题行高:     1.5
标题字号:     H1=24-26px / H2=19-20px / H3=17px
容器最大宽度: 677px
内边距:       左右16px
列表项间距:   10px
```

## 如何选择主题

1. **用户明确指定** → 直接用（"用棱镜风"/"来个杂志风"/"aurora"）
2. **用户没指定** → 按文章类型推荐：
   - 科普解析 → `handdrawn` 或 `storybook`（叙事感适合教学）
   - 实战复盘 → `geek` 或 `prism`（技术实战）
   - 工具测评 → `cartoon` 或 `aurora`（轻松活泼）
   - 深度思考 → `editorial` 或 `ink`（厚重感）
   - 技术教程 → `minimal`（步骤清晰）
   - AI前沿/模型发布 → `prism`（科幻感）
   - 文化/人文交叉 → `landscape`（东方美学）
   - 行业分析 → `editorial`（杂志权威感）
3. **用户说"随便/你定"** → 默认 `handdrawn`

## v5/v5.2 新增主题设计说明

参考精品演示文稿风格（衬线极简/柔光光晕/暗黑渐变/东方山水/故事书/活动宣发），不照抄，全部针对公众号场景重新设计：

- **editorial**：取自杂志排版传统（kicker眉题+byline+首字下沉+拉页引语），红色编辑标记贯穿
- **aurora**：柔和渐变只做浅底色块，正文保持白底；渐变色全部低饱和，避免刺眼
- **prism**：暗色块只用于标题/金句/代码/预告/签名五个"重音"位置，正文白底，明暗交替形成节奏
- **landscape**：与 ink（黑白墨）区分，青绿+黛蓝+朱砂三色体系，"卷一/卷二"章节编号
- **storybook**：双线书页框+首字下沉+"第一章"装饰框+✦❧花饰，叙事感最强
- **launch（v5.2 新增）**：深蓝 #1E40AF + 亮黄 #F4E94B 双色体系，针对"活动预告/Meetup 招募/Workshop 招生"场景设计——海报图片加白框+阴影、CTA 用胶囊色块、现场快报用黑底黄字、章节标题用大号蓝块编号、签名用蓝色色块卡片，活动节奏感最强
