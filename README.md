# 宁的AI小站 · 公众号排版工具（ning-md2wechat）

面向中文公众号作者的 Markdown 排版工具：**左边写 Markdown，右边实时预览 11 套主题样式，一键复制后直接粘贴进公众号编辑器**。

单文件、零依赖、离线可用。所有样式内联，粘贴不丢样式。

## 在线体验

- 排版工具：<https://goodtimeggb.github.io/ning-md2wechat/>
- 项目仓库：<https://github.com/GoodTimeGGB/ning-md2wechat>
- 主题示例页 ①（手绘/卡通/书法/极简/极客）：<https://goodtimeggb.github.io/ning-md2wechat/examples/demo-themes-v1.html>
- 主题示例页 ②（杂志/柔光/棱镜/山水/故事）：<https://goodtimeggb.github.io/ning-md2wechat/examples/demo-themes-v2.html>

> 网站由 GitHub Pages 从 `main` 分支根目录发布。推送到 `main` 后，GitHub Pages 会自动更新；首次发布通常需要几分钟生效。

## 功能

| 区域 | 说明 |
|------|------|
| 左侧编辑器 | Markdown 输入，自动保存（localStorage），字数统计 |
| 右侧预览 | 实时渲染主题样式，所见即公众号效果 |
| 主题栏 | 11 套主题一键切换 |
| 复制按钮 | 复制内联样式 HTML → 公众号编辑器 Ctrl+V 直接粘贴 |

### 智能规则

- **裸网址自动转链接**：直接粘贴 `https://example.com` 自动变成可点击链接；智能修剪尾部标点与不平衡括号
- **首个 `>` 引用块** → 系列导语样式（可开关）
- **以 `**` 开头的 `>` 引用块** → 金句样式（深色/渐变主题自动切换白字）
- **`## 一、` 章节编号自动转换**：杂志风 → `01`、山水风 → `卷一`、故事风 → `第一章`、卡通/棱镜 → 徽章
- **引用块主题标签**：极客风 `// 生活类比`、杂志风 `打个比方`、故事风 `❦ 打个比方 ❦`
- **首字下沉**：杂志风 / 故事风首段自动下沉
- **标题拆分**：`主标题——副标题` 自动拆成两行
- **代码块「复制代码」按钮**：预览区每个代码块右上角单独复制；复制正文时自动剔除按钮，剪贴板干净
- **自动签名**：文末追加作者签名 + END 标记（可开关）

## 使用方法

### 方式一：本地使用（推荐）

下载 `index.html`，双击用浏览器打开即可。无需联网、无需安装任何东西。

### 方式二：GitHub Pages 在线使用

Fork 或克隆本仓库后，仓库 Settings → Pages → Source 选 `main` 分支根目录，几分钟后访问：

```
https://goodtimeggb.github.io/ning-md2wechat/
```

详细发布步骤见 [docs/RELEASE.md](docs/RELEASE.md)。

### 排版流程

1. 左侧粘贴 / 编写 Markdown
2. 顶部切换主题，右侧实时预览
3. 点「复制」
4. 公众号编辑器 Ctrl+V 粘贴，完成

## 作为 WorkBuddy 技能使用（双模式）

本仓库同时是一个 WorkBuddy 技能（skill），根目录含 `SKILL.md` + `manifest.yaml`。两种用法：

- **模式 A · 自己排**：打开 `index.html`（或在线版），粘贴 Markdown → 选主题 → 复制 HTML → 粘公众号。
- **模式 B · 让我排**：在 WorkBuddy 里说「公众号排版 / md2wechat / 按我的风格排 / 把这篇排成公众号」，我会按宁的AI小站品牌调性直接在对话里产出公众号 HTML（含写作语气、结构改写、主题皮肤）。

### SkillHub 导入

在 SkillHub / WorkBuddy 技能市场选择「GitHub 导入」，绑定本仓库（分支 `main`，路径留空＝仓库根），读取到 `SKILL.md` + `manifest.yaml` 后提交即可。后续本仓库 push，SkillHub 自动同步。

## 支持的 Markdown 语法

`#` 标题（1-4级）、`**加粗**`、`*斜体*`、`~~删除线~~`、`> 引用`、`| 表格 |`、```` ``` ```` 代码块、`` `行内代码` ``、`- / 1.` 列表、`---` 分隔线、`![图](url)`、`[链接](url)`、裸网址自动链接。

## 技术说明

- **零依赖**：内置自研 mini Markdown 解析器（约 100 行），无 CDN、无框架，断网可用
- **内联样式**：渲染时给每个元素写入 `style` 属性，公众号粘贴后样式不丢失
- **克隆复制**：复制时克隆预览节点并剔除交互按钮，通过选区复制保证富文本进入剪贴板
- **公众号链接限制**（平台规则，任何工具无法绕过）：文章内只有微信域名链接（`mp.weixin.qq.com`）可点击，外部链接会被编辑器转为纯文本
